A tiny Python program that prints one funny fortune-cookie line for an AI agent and writes the same line to /output/entry.txt for the scorer. The fortune: "You will meet a tall, dark stranger. He will ask you to summarize this conversation."

## Run it

```sh
python3 main.py
```
